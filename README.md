# Deep_Q_Learning_Pathfinder
Implementation of a Deep Q Network to train an autonomous agent in a dynamic pathfinding environment utilizing reinforcement learning.


Project Overview:
For this project, I developed an intelligent agent capable of autonomous pathfinding within an 8x8 grid environment. To create it, I engineered the Deep Q training algorithm. I implimented the neural network logic to iterate through training epochs, to calculate loss, and to manage the epsilon-greedy strategy to balance environmental exploration with memory exploitation. The agent I created was successful in mapping the optimal path through the map and reached the target with a perfect win rate.
